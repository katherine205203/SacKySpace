# SacKy

SacKy is a web-first React and TypeScript application powered by Vite.

The current codebase contains only the responsive application shell and a
placeholder Home screen. Product modules, authentication, data services, and
native integrations will be added deliberately in later steps.

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run build
npm run lint
```
